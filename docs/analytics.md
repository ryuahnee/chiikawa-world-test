# Private usage dashboard

Project: 693920 (Default project). Dashboard: https://us.posthog.com/project/693920/dashboard/2271442 . IP discard enabled, timezone Asia/Seoul, public sharing disabled. Production collection is enabled by GitHub Actions repository variables POSTHOG_PROJECT_TOKEN and POSTHOG_API_HOST, injected at release build; local builds default off.

Use the owner's PostHog account. Do not enable public sharing or invite others. A secret personal API key must never be shipped in dist or committed.

Dashboard (last 30 days, daily intervals):
- Visits: total count of site_visit.
- Quiz starts: total count of quiz_started.
- Completions: total count of quiz_completed.
- Result distribution: quiz_completed total count, breakdown by character_id, pie chart.
- Completion funnel: site_visit → quiz_started → quiz_completed, within one visit.

Character IDs: c 치이카와, h 하치와레, u 우사기, m 모몽가, r 랏코, s 시사, k 쿠리만쥬.

Visits mean page loads, not unique people. Reloads count again. Shared result links count as visits, never as quiz completions. Retries count as additional starts and completions. Ad blockers and network failures may reduce counts. Data starts at activation; historical visits cannot be recovered.

Implementation sends only the three allowlisted events, release version and completed character ID. An in-memory random visit ID links the funnel and changes on reload. No answers, names, emails, URL, query parameters, referrer, persistent browser IDs, cookies, replay or autocapture are sent by the code. GeoIP enrichment and person profile processing are disabled. The service still receives network metadata while handling requests; this is not a promise of zero personal-data processing. Before activation, enable the project's IP-discard setting as well and verify one real event in PostHog.

Activation:
1. Install and connect PostHog with the owner's account; select/create the project.
2. Enable project IP discard. Leave replay/autocapture and public dashboard sharing off.
3. Set POSTHOG_PROJECT_TOKEN and POSTHOG_API_HOST as repository release variables. dist/analytics-config.js is generated by the release script. Never hard-code values in source.
4. Create the five dashboard tiles above in the authenticated project.
5. Prepare release, run tests, deploy, finish one quiz and verify events and private dashboard access.
