# 확정 구현 기준

- 제목: 눈 떠보니 치이카와 세상
- 모바일 우선, 로그인 없이 약 2분, 질문 8개 × 선택지 3개
- 풀밭 도착 → 일 고르기 → 친구 만나기 → 간식 → 위로 → 수레 돕기 → 저녁 → 하루 마무리
- 결과: 치이카와, 하치와레, 우사기, 모몽가, 랏코, 쿠리만쥬
- 각 선택지는 주된 성향 +2점, 보조 성향 +1점
- 동점: 총점 → 주된 성향 횟수 → Q7·Q6·Q5·Q2·Q1·Q3·Q4·Q8 배점 순
- 정확한 문항, 선택지, 배점 및 결과 문구는 `dist/data.js`가 기준
- 크림색 배경, 파스텔 포인트, 둥근 카드와 그림책 느낌
- 이전 질문으로 돌아가기, 결과 URL 공유, PNG 카드 저장, 다시 하기
- 답변을 서버에 저장하지 않음. 결과 ID만 URL 해시로 공유
- 비공식 팬 콘텐츠이며 재미용 성향 테스트임을 표시
- 백엔드·DB·로그인·통계는 범위에서 제외
