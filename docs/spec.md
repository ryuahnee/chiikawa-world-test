# 확정 구현 기준

- 제목: 눈 떠보니 치이카와 세상
- 모바일 우선, 로그인 없이 약 3분, 질문 10개 × 선택지 3개
- 풀밭 도착 → 일 고르기 → 친구 만나기 → 다시 시도하기 → 간식 → 위로 → 수레 돕기 → 함께 마무리하기 → 저녁 → 하루 마무리
- 결과: 치이카와, 하치와레, 우사기, 모몽가, 랏코, 시사, 쿠리만쥬
- 각 선택지는 주된 성향 +2점, 보조 성향 +1점
- 캐릭터별 점수 기회 차이는 고정 배율과 작은 보정값으로 조정. 무작위 추첨 없이 보정 총점으로 결과 결정
- 동점: 주된 성향 횟수 → Q4·Q8·Q7·Q6·Q3·Q2·Q1·Q5·Q9·Q10 배점 순
- 직접 완료한 결과 화면에는 Q4(배우는 방식), Q8(함께 일하는 방식)의 선택별 설명 추가. 결과 ID만 공유한 링크에는 답변 기반 설명을 표시하지 않음
- 정확한 문항, 선택지, 배점 및 결과 문구는 `dist/data.js`가 기준
- 크림색 배경, 파스텔 포인트, 둥근 카드와 그림책 느낌
- 이전 질문으로 돌아가기, 결과 URL 공유, PNG 카드 저장, 다시 하기
- 답변을 서버에 저장하지 않음. 결과 ID만 URL 해시로 공유
- 비공식 팬 콘텐츠이며 재미용 성향 테스트임을 표시
- 백엔드·DB·로그인·통계는 범위에서 제외
